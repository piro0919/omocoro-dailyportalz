# Omocoro × Daily Portal Z

> Daily article aggregator for [Omocoro](https://omocoro.jp/) and [Daily Portal Z](https://dailyportalz.jp/).

[🔗 Live Site](https://omocoro-daily.kk-web.link)

## ✨ Features

- 📰 Unified feed from two Japanese humor sites
- 📅 Date-grouped article list
- 📱 PWA support for mobile reading

## 🛠 Tech Stack

- Next.js + React + TypeScript
- next-pwa

## 🚀 Development

```bash
pnpm install
pnpm dev
```
